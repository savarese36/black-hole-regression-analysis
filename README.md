# Overview

This project investigates whether brighter optical outbursts in black holes are associated with stronger X-ray detectability while accounting for the effects of distance.

Using data from the BlackCAT catalog, I applied Signal Detection Theory concepts to astronomical observations and evaluated relationships using correlation and regression analysis.

# Methods
- Data preprocessing
- Feature engineering
- Pearson correlation analysis
- Simple linear regression
- Multiple linear regression
- Statistical significance testing

# Tools
- SAS
- Statistical Modeling
- Data Analysis
- Data Visualization

# Key Findings
- Distance was the strongest predictor of observed X-ray flux.
- Larger outbursts showed a modest positive relationship with detectability.
- Results were consistent with Signal Detection Theory, demonstrating how observational noise can obscure signals.
